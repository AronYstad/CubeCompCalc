# Cube Competition Calculator

Link to website: https://aronystad.github.io/CubeCompCalc/

A tool for calculating best possible average, worst possible average and time needed for PR in WCA competitions.

## How to use:
- Enter WCA ID to fetch PRs, or choose the format and manually enter PR.
- Enter the times from the competition.
- After enough times have been entered, statistics will start to be displayed at the bottom of the page.
